Tentang Saya

Saya adalah seorang Data & BI Professional dengan pengalaman mendalam di persimpangan antara teknologi, bisnis, dan analitik. Saat ini berperan sebagai IT Data & ERP System di Gandasari Group Investama — sebuah perusahaan holding multi-industri.

Keahlian utama saya adalah menerjemahkan data mentah dari berbagai sistem ERP menjadi dashboard visual yang bisa langsung ditindaklanjuti oleh manajemen. Saya percaya bahwa data yang baik seharusnya membuat keputusan menjadi lebih mudah, bukan lebih rumit.

Latar belakang saya di operasional bisnis sebelum masuk ke dunia data memberi saya keunggulan: saya tidak hanya memahami teknisnya, tapi juga konteks bisnisnya.
